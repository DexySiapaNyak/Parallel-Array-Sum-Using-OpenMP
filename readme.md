## Deskripsi Proyek

Proyek ini bertujuan membandingkan performa perkalian matriks menggunakan metode sequential dan parallel dengan OpenMP pada bahasa C++.

## Fitur

- Sequential Matrix Multiplication
- Parallel Matrix Multiplication
- Benchmark Waktu Eksekusi
- Perhitungan Speedup

## Cara Menjalankan

Compile:

g++ src/main.cpp -fopenmp -O2 -o main

Run:

.\main.exe

## Hasil Pengujian

Program menghasilkan perbandingan waktu eksekusi antara metode sequential dan parallel.
